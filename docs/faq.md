## 启动相关

### 打开后白屏 / 一片透明

先确认 WebView2 Runtime 是否安装。Win11 自带，Win10 部分精简版系统会缺失。

## 使用相关

### 她在桌面上不见了

可能被拖到了屏幕外。右键托盘图标 → 重置位置，或重启应用。

### 换显示器后位置错乱

多显示器且缩放比例不同时容易发生。同上，重置位置即可。

### 对话突然不回了

按顺序排查：模型配置是否还有效 → 供应商是否欠费或限流 → 网络是否通。设置页的「测试连接」能快速定位前两项。

## 更新相关

### 更新后配置丢了

正常不会。更新只替换程序文件，配置在用户目录下。如果确实丢了，检查是否换了 Windows 用户账号。
