# QQ 接入

让 Doro 住进 QQ：你发消息，她回。有两种接法，可以同时开。

## 两条通道，先选一条

| 通道 | 身份 | 适合谁 |
| --- | --- | --- |
| **官方机器人** | 独立的机器人身份，不是你本人 | 想省事、不想折腾部署的人 |
| **NapCat** | **你自己的 QQ 号** | 想让她用你本人的号说话 |

页面上左上角切换只决定「现在看哪一页」，**不会停掉另一条**。两条各自连接状态，选择器上有小圆点标着。

::: tip 两者可以一起开
官方机器人挂在群里、NapCat 用你自己的号私聊——两种场景同时跑没问题，互不干扰。
:::

---

## 通道一：官方机器人

不用装任何东西，手机扫码就行。

### 步骤

1. 左侧导航进 **「QQ 接入」**，左上角切到 **「官方机器人」**
2. 点 **扫码**，屏幕上出现二维码
3. **用手机 QQ 扫这个码**
4. 扫码页里如果没有现成的机器人，**可以直接创建**——「还没有机器人也没关系」
5. 授权完成后自动保存凭证并连接，状态变成「已上线」

连上之后标题会显示机器人名字，比如「已上线 · 某某」。

### 二维码会过期

放着不管大概几分钟就失效。过期后点 **「重新扫码」** 重新走一遍。

扫码成功后如果提示「保存失败」，说明凭证拿到了但没写进配置文件——按提示手动检查一下，或者重新扫一次。

### 也可以手动填凭证

不想扫码的话，面板下方有 **AppID** 和 **AppSecret** 两个输入框，从 QQ 开放平台复制过来填上即可。

## 通道二：NapCat

用你自己的 QQ 号收发消息。代价是要先有 NapCat 这个中间层。

### 步骤

1. 左侧导航进 **「QQ 接入」**，左上角切到 **「NapCat」**
2. **安装 NapCat**。软件可以帮你装，页面会显示安装位置（「已安装到 …」）；你也可以自己装好再来接
3. **启动 NapCat 并登录 QQ**。页面状态会显示「运行中，等待登录」，登录成功后自动检测到
4. **填 WebSocket 地址**。默认 `ws://127.0.0.1:3001`，和 NapCat 那边的配置保持一致
5. **点「连接」**

::: warning 改完配置要重启 NapCat
如果页面提示「配置已写入，重启 NapCat 后点『连接』」，那说明 NapCat 的配置文件被改过了。**必须先重启 NapCat**，否则新配置不生效，连接会一直失败。
:::

### 各字段的作用

| 字段 | 说明 |
| --- | --- |
| **QQ 号** | 可选，用来标识这是哪个号 |
| **WebSocket 地址** | 默认 `ws://127.0.0.1:3001`，除非你改过 NapCat 的端口 |
| **触发词** | 见下 |

### 触发词怎么用

决定在群里怎么才会回应她：

- **留空** → 群里只有 **@ 她** 才回复
- **填一个词**（比如「小d」）→ 消息里带上这个词就触发，不用 @

私聊不受这个限制，直接说话就行。

## 回复策略

| 选项 | 行为 |
| --- | --- |
| **被 @ 时回复** | 群里被 @ 才回，最安静 |
| **所有消息都回复** | 群里每句都回，容易刷屏 |
| **跟随对话页默认** | 沿用桌面端的设置 |

群聊建议用「被 @ 时回复」或者配一个触发词，否则一个活跃的群能让她刷到停不下来。

## 语音

| 选项 | 行为 |
| --- | --- |
| **不发语音（只发文字）** | 最稳，兼容性最好 |
| **仅私聊发语音** | 私聊语音，群里仍然只发文字 |

QQ 侧发语音依赖 TTS 配置，和桌面端共用一套音色设置。

## 允许在 QQ 侧使用工具

这个开关决定她能不能在 QQ 里动用工具（读文件、执行命令等）。

::: danger 远程触发高危工具有风险
打开之后，任何能给这个 QQ 发消息的人，都可能通过对话让她执行工具。

尤其是 `run_command`（执行命令）和 `write_file`（写文件）——**群聊场景下务必谨慎**。建议：
- 只在私聊或小范围可信的群里打开
- 配合工具权限的逐次确认使用，不要对写操作设「始终允许」
:::

## 独立配置

QQ 接入的**模型、音色、可用工具**都是单独一套，和桌面端互不影响。

也就是说你可以让桌面上的 Doro 用一个大模型闲聊，QQ 里换成便宜的小模型；或者桌面端开工具、QQ 侧全部关掉。

## 权限确认

在 QQ 里让她动文件时，会先在聊天里弹一条确认消息——你点同意才会执行。

这层确认和桌面端的权限卡片是两套，目的相同：防止远程一句话就把你的文件改了。

## 常见问题

### 扫码后一直「正在连接」

网络问题或者二维码过期。先点「重新扫码」，还不行就看页面下方的「最近日志」——那里会打出具体的失败原因。

### NapCat 显示未运行

NapCat 进程没起来。去 NapCat 那边确认它在跑，登录窗口是不是卡在扫码/密码页。

### 群里 @ 了她不回

三个地方查：回复策略是不是「被 @ 时回复」、触发词有没有配错、以及这个群里机器人有没有发言权限。

### 她回了但内容重复

大概率是两条通道同时连了同一个群，同一条消息被处理了两次。关掉其中一条。

### 换电脑要重新配吗

要。凭证和 NapCat 配置都保存在本地数据目录里，不跟随账号同步。
