# 直播间

把桌面变成直播间：画面由 OBS 采集，弹幕、点歌和画面布局都在 DoroPet 里管。

## 整体结构

| 部分 | 作用 |
| --- | --- |
| 直播窗口 | 画面主体，默认处于推流态（无编辑控件） |
| 控制台 | 主窗口里的三页签，管顶栏、弹幕、点歌 |
| OBS | 通过浏览器源引入直播窗口的画面 |

## 接入 OBS

1. 打开 DoroPet 的直播控制台，记下本机地址。
2. 在 OBS 里新建「浏览器」源，填入该地址。
3. 分辨率与帧率按 OBS 推荐值设置。

## 编辑模式

直播窗口默认是干净的推流态，看不到任何按钮。需要调整布局时，在主界面的开关里进入编辑模式，窗口内只保留「完成编辑」和 Esc 退出。

## 舞台背景

支持多种舞台形态，可以在设置里切换。切换是热生效的，不需要重启。

## 大屏位
