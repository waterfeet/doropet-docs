# 功能总览

DoroPet 由三块能力组成，可以单独用，也可以串起来用。

| 模块 | 一句话说明 | 详见 |
| --- | --- | --- |
| 桌面宠物 | 一个常驻桌面的透明窗口，可拖拽、缩放、右键操作 | [桌面宠物](/features/pet) |
| AI 对话 | 接自己的模型，配人设，支持工具调用 | [AI 对话](/features/chat) |
| 音乐与歌词 | 搜索播放，歌词可视化 | [音乐与歌词](/features/music) |

## 它们怎么配合

三个模块运行在同一个应用里，从左侧导航切换。桌宠是常驻的那部分——即使你切到别的页面，她仍然待在桌面上。

对话是入口。配好模型、人设和工具之后，她能在聊天里直接调用应用的能力，不用你在各个页面之间来回找按钮。
