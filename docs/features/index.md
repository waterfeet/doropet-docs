# 功能总览

DoroPet 的能力分成十块，可以单独用，也可以串起来用。

| 模块 | 一句话说明 | 详见 |
| --- | --- | --- |
| 桌面宠物 | 常驻桌面的透明窗口，可拖拽、缩放、右键操作 | [桌面宠物](/features/pet) |
| 养成与 Doro 币 | 三条属性会随时间衰减，赚币买东西养她 | [养成与 Doro 币](/features/growth) |
| AI 对话 | 接自己的模型，配人设，支持工具调用 | [AI 对话](/features/chat/) |
| 音乐与歌词 | 两个音源，桌面歌词与全屏可视化 | [音乐与歌词](/features/music) |
| 灵动岛 | 屏幕顶部的细信息条，显示时钟、播放、占用 | [灵动岛](/features/island) |
| QQ 接入 | 让 Doro 住进 QQ，两条通道可选 | [QQ 接入](/features/qq) |
| 五子棋 | 和她下一盘，赚 Doro 币最快的路 | [五子棋](/features/gomoku) |
| 备忘与提醒 | 记一件事，到点让 Doro 提醒你 | [备忘与提醒](/features/memo) |
| 工作流 | 把固定的多步任务做成可复用的流程（实验性，可能移除） | [工作流](/features/workflow) |
| 其他功能 | 备忘录、技能、终端、系统优化、日志 | [其他功能](/features/others) |

## 它们怎么配合

所有能力跑在同一个应用里，从左侧导航切换。桌宠和灵动岛是常驻的那两块——即使你切到别的页面，它们仍然在屏幕上。

对话是入口。配好模型、人设和工具之后，她能在聊天里直接调用应用的能力，不用你在各个页面之间来回找按钮。

QQ 接入则是把同一套能力搬到手机上用——模型和工具是独立的一套配置，见 [QQ 接入](/features/qq)。
