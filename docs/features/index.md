# 功能总览

DoroPet 由四块能力组成，可以单独用，也可以串起来用。

| 模块 | 一句话说明 | 详见 |
| --- | --- | --- |
| 桌面宠物 | 一个常驻桌面的透明窗口，可拖拽、缩放、右键操作 | [桌面宠物](/features/pet) |
| AI 对话 | 接自己的模型，配人设，支持工具调用 | [AI 对话](/features/chat) |
| 音乐与歌词 | 搜索播放，歌词可视化 | [音乐与歌词](/features/music) |
| 直播间 | 推流、弹幕、点歌、舞台背景 | [直播间](/features/live) |

## 它们怎么配合

对话是中枢，音乐和直播是场景。比如在直播间里，观众点歌会进入播放队列，而 Doro 会用语音把流程讲出来——这条链路把三个模块串在了一起。
