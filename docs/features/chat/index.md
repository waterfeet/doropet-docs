# AI 对话

对话是整个应用的核心，也是最复杂的一块。它不只是「一个输入框和一堆回复」——会话、工作区、角色、工具、记忆这几样东西是互相咬合的。

这组页面按能力拆开讲，每一篇对应界面上的一个区域。

## 先建立整体印象

| 概念 | 是什么 | 详见 |
| --- | --- | --- |
| **会话** | 一次连续的对话，有独立的上下文和工作区 | [会话管理](/features/chat/conversation) |
| **工作区** | 跟着会话走的文件空间，AI 读写文件都在这里面 | [工作区](/features/chat/workspace) |
| **角色** | 决定她用什么身份、什么语气、能不能调用工具 | [角色与人设](/features/chat/persona) |
| **工具** | 让她能查时间、搜网页、读文件、放音乐…… | [工具调用](/features/chat/tools) |
| **记忆** | 跨会话保留的信息，下次对话能想起来 | [记忆](/features/chat/memory) |
| **语音** | 说给她听（系统听写）和听她说（TTS） | [语音输入与朗读](/features/chat/voice) |
| **图片** | 粘贴、上传、截图，以及她能不能看懂 | [图片与截图](/features/chat/image) |

## 它们怎么串起来

一次典型的对话是这样的：

1. 你新建一个**会话**，这个会话会创建一个专属的**工作区**目录
2. 会话绑定了某个**角色**，角色的系统提示词决定她的说话方式
3. 你发一句话，模型决定要不要调用**工具**
4. 如果要调工具，界面弹卡片问你是否允许
5. 涉及文件的工具，只能碰**工作区**里的东西
6. 值得长期记住的信息，她会写进**记忆**，下次别的会话也能用

## 建议的阅读顺序

第一次用，按 [会话管理](/features/chat/conversation) → [角色与人设](/features/chat/persona) → [工具调用](/features/chat/tools) 的顺序看。

已经会聊天了，只想搞懂某个功能，直接跳对应那一篇。
