# 会话管理

会话（conversation）是一次完整的对话。每个会话有独立的上下文和独立的工作区，互不干扰。

## 新建会话

对话页左侧是会话列表，顶部有 **「新建对话」**。

点下去会创建一条空会话，同时为它准备一个专属工作区目录。

右侧在没有选中会话时显示「选择或新建一个对话」，选中后变成「开始对话吧」。

## 切换与删除

点列表里的任意一条即可切换。切换后上下文完全跟着变——每个会话的模型看到的是自己那段历史，不会串。

列表顶部有个多选按钮，进入后可以勾选多条**批量删除**。删除的是对话记录，没有回收站。

::: tip 工作区文件不受影响
删会话只删对话记录，对应的**工作区目录和里面的文件会原样保留**。要清掉文件得去左侧导航的「工作区」页单独删，详见 [工作区](/features/chat/workspace#删会话不删工作区)。

所以删会话时不用心疼文件；反过来，也别指望删会话能腾出空间——删得多了，工作区目录只会一个个攒着。
:::

## 发送消息

输入框支持这些操作：

| 操作 | 方式 |
| --- | --- |
| 发送 | `Enter` |
| 换行 | `Shift + Enter` |
| 粘贴图片 | 直接 `Ctrl + V` |
| 调整高度 | 内容变长时输入框自动撑高 |

输入法兼容做了处理——中文输入法选词时按回车不会误发送，选完再按才发送。

## 生成过程中

发送后按钮会变成 **停止** 图标，点一下中断生成。

中断不是删除：已经吐出来的内容会保留在消息里，你可以接着追问，也可以点「重新生成」让它重来一遍。

::: tip 什么时候该中断
回复明显跑偏、或者你已经看到想要的答案时，中断比等它写完更省 token——计费是按实际输出算的，截断就只付截断前的部分。
:::

## 消息上的操作

每条消息（你的和她的）都带一组操作：

| 操作 | 说明 |
| --- | --- |
| **复制** | 复制正文纯文本 |
| **编辑** | 改自己发出去的内容。改完通常会重新触发生成 |
| **撤回** | 收回刚发出、还没被回复的那条 |
| **重新生成** | 让模型重答一遍，旧的回答被替换 |
| **朗读** | 用 TTS 念出来。朗读中会变成「停止朗读」 |
| **转发到宠物对话框** | 把这条内容发到桌面上的 Doro 气泡里 |
| **删除** | 删掉单条消息 |

「转发到宠物对话框」在你想让桌面上也看到某段内容时比较有用，比如让她把一段总结「说」到桌面上。

## 用量

对话顶部会显示这一轮消耗的 token 数（悬浮可看细节）。不同供应商的计费口径不一样，这里显示的是接口返回的用量，不代表最终账单。

## 常见问题

### 发出去没反应

看停止按钮有没有出现。如果没有，可能是模型配置失效了——去 [配置对话模型](/guide/model-setup) 里的错误对照表查。

### 上下文突然「失忆」

会话太长，早期消息被截断了。开新会话、或者把关键信息让它记进 [记忆](/features/chat/memory)。

### 想找回删掉的对话

找不回来。删除是物理删除。
