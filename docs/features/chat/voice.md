# 语音输入与朗读

两个方向：你说给她听，和她念给你听。

## 语音输入：其实是调系统听写

这里要先说清楚一件事，否则容易以为功能坏了。

DoroPet **不做语音识别**。点输入框左边的麦克风按钮，它做的是**唤起 Windows 自带的听写**（快捷键 `Win + H`），识别工作由系统完成，识别出来的文字直接落进输入框。

所以：

- 麦克风按钮不是「按住说话」，是「打开系统的语音输入面板」
- 面板出来之后你就正常说话，文字会实时出现在光标处
- 说完再按一次 `Win + H` 或点面板上的停止，结束输入

::: tip 点了没反应
界面会提示「正在听写…若没反应，请手动按 Win+H」。如果按了 `Win + H` 还是没出现面板，去 Windows 设置 → 辅助功能 → 语音，确认「语音输入」是开的，并且麦克风权限给了。
:::

### 需要在系统里配好

第一次用之前，Windows 可能要求你完成一次语音识别设置（选择麦克风、朗读一段话校准）。这一步在系统设置里做，不归 DoroPet 管。

配好之后，任何应用里按 `Win + H` 都能用，不光是在这里。

### 生成中不能用

她正在回复时，麦克风按钮是灰的。等生成结束或者点停止之后再说话。

## 朗读：让她念出来

反过来，她回复完之后可以点消息上的「朗读」，用 TTS 念出来。

朗读中那个按钮会变成「停止朗读」，随时可以掐掉。

### 需要先配 TTS

朗读用的是 TTS 模型，和对话模型是两套配置。在 [模型 → 语音合成](/guide/model-setup#另外两个页签-语音与绘图) 里配，**Edge TTS 是内置的，不用配任何东西就能用**。

### 自动朗读

每次都手动点太麻烦。设置里打开 **「自动朗读」** 后，她每回复完就自动念。

这个开关和桌宠的「Doro 说话」是相关的——桌宠主动说话、启动播报也都走同一套 TTS。

::: tip 播报时会自动压低音乐
开启朗读后，播报期间背景音乐音量会自动降下来，念完恢复。起播和结束各有一声轻提示音，不用一直盯着屏幕确认她念完没有。
:::

## 常见问题

### 听写出来的字不对

系统听写对专业术语和英文缩写的识别一般。改两句比重新说一遍快。

### 朗读声音很机械

换音色。Edge TTS 里 `zh-CN-XiaoxiaoNeural` 这类自然度较高，编号靠后的音色通常更生硬一些。MiMo TTS 支持音色设计，可以按描述生成更符合角色的声音。

### 朗读到一半断了

检查网络——Edge TTS 是在线的，断网就念不了。想完全离线只能选 Web Speech API（音质差）。

### 想让 Doro 用自己的声音说话

在 TTS 配置里换音色，桌宠和对话朗读共用同一套配置。想要独一无二的声音，用 MiMo 的「音色克隆」上传一段样本。
