# 图片与截图

三种把图送进去的方式：上传、粘贴、截图。它们落到同一个地方——输入框上方的待发送区。

## 上传

点输入框左边的图片按钮，选文件。支持多选，一次挑好几张。

## 粘贴

最快的方式。复制图片（截图工具、网页右键复制图片、微信里复制的图都行），在输入框里按 `Ctrl + V`。

文本粘贴照常；只有剪贴板里是图片时才触发上传。

## 截图

点剪刀图标，屏幕会进入选框状态，拖一块区域截下来直接进待发送区。

剪刀右边有个小箭头，可以选截图时要不要隐藏主窗口：

| 模式 | 适用场景 |
| --- | --- |
| **截图时隐藏主窗口** | 截别的东西。主窗口不挡着，也不会把自己拍进去 |
| **截图时不隐藏主窗口** | 截 DoroPet 自己。比如截一段对话给她看 |

::: tip 默认建议选「隐藏」
否则你截出来的图里永远有个窗口边缘。两种模式的偏好会被记住，选一次就行。
:::

## 待发送区

选好的图显示在输入框上方，每张带缩略图和移除按钮。**图不会立刻发出去**，要等你按下发送。

所以可以连挑几张、全部检查一遍、去掉不要的，再一起发。

## 她能不能看懂

取决于模型。

带视觉能力的模型（GPT-5.5、Claude 5.5 系列、Gemini、DeepSeek V4.1 Flash 等）能真的读图内容；纯文本模型收到图片会被剥掉，然后回答「我看不到图片」。

软件现在会**按模型规格自动判断**是否支持视觉，不需要你手动勾选。模型配置里的「图片理解」那一栏是只读的提示。

::: warning 如果她总说「看不到图片」
先确认当前模型是不是纯文本模型。DeepSeek 的 V4 Pro 就是纯文本（`input: ["text"]`），发图会被静默剥掉。换成 V4.1 Flash 或视觉模型再试。
:::

## 图片上下文

发过一张图之后，继续追问「图里那个按钮是干嘛的」，她能翻回你之前发的那张图，不用重发。

同一张图不会被重复传输——这既是省 token，也避免上下文里堆同一张图好几份。

## 典型用法

**报错排查**：截一段报错截图，问「这是怎么回事」。

**界面还原**：截一个网页或软件的界面，说「照这个风格写个类似的」。

**看图说话**：截图里是表格，让她「把这张表转成 markdown」。

**对着图改**：发一张截图，问「这个布局哪里不对劲」。

## 注意事项

### 图片会占上下文

一张高分辨率图片消耗的 token 相当可观，多图长对话更容易触发截断。用完的图不用刻意删——上下文管理是自动的——但如果发现她「忘了」更早的对话，多半是图把它们挤掉了。

### 别发敏感图

图片会随请求发到模型供应商的服务器。密钥、身份证、内部文档这类，自己判断。

### 截图失败

少数全屏独占的应用（部分游戏、播放器）截不到，会得到黑图。用系统截图工具截好再粘贴。
