# 工作区

工作区是每个会话专属的文件空间。AI 读写文件、你预览文件，都在这个范围内进行。

## 它是怎么来的

新建会话时自动创建，和会话一一对应。**默认**位于：

```
%APPDATA%\com.waterfeet.doropet\workspaces\<会话 ID>
```

`com.waterfeet.doropet` 就是应用的数据目录，这个位置可以改——见 [改存放位置](#改存放位置)。

平时不用记路径，界面里点「打开工作区」会直接调起资源管理器。

## 两个入口

工作区在两处能进，用途不一样。

### 对话页右侧面板

只显示**当前会话**的工作区，用来边聊边看文件。

| 元素 | 作用 |
| --- | --- |
| 文件列表 | 显示会话工作区里现有的文件，带文件数统计 |
| 打开工作区 | 在资源管理器里打开这个目录 |
| 预览 | 点文件看内容，不离开对话页 |
| 导入 | 把外部文件放进工作区 |

预览支持 Markdown——可以切源码和渲染后的效果。

### 左侧导航的「工作区」页

列出**所有会话**的工作区，每条显示会话标题和文件数，可以逐条打开或删除。

这里是清理空间的地方——对话页那个面板只管当前会话，看不到也删不掉别的会话留下的文件。

## 改存放位置

工作区是**数据目录**的子目录，所以没法单独挪工作区——要改就整个数据目录一起搬。

入口在工作区页顶部那张「数据目录」卡片：

1. 卡片显示当前路径和总占用（工作区已算在里面）
2. 点「迁移…」展开迁移面板
3. 输入新路径，或点「浏览…」选一个目录
4. 点「迁移并重启」

### 迁移实际做了什么

- 把当前数据目录里的**全部数据复制**到新位置——对话记录、记忆、歌单、工作区文件、QQ 接入配置都在内
- 在原来的目录里写一个 `.data_dir.json`，记下新路径，下次启动按它找
- 然后重启应用

::: warning 是复制，不是剪切
原目录里的数据**不会被删除**，会原样留着。

确认新位置能正常工作之后，可以手动删掉旧的来释放空间。但别急着删——先让应用在新位置跑一轮，确认对话记录和工作区文件都还在，再动手。
:::

::: danger 迁移过程中不要关程序
复制是逐文件进行的。中途强行结束，可能只搬了一半，新旧两处都不完整。
:::

### 什么时候值得迁移

C 盘吃紧的时候。数据目录里最占地方的是工作区文件和日志，长期用下来能到几个 G。

## 为什么要有工作区

两个原因。

**一是安全边界。** AI 的文件工具（读、写、改、列目录）被限制在工作区内，它没法随便翻你 C 盘里的东西。这是「能干活」和「能安全干活」之间的一条线。

**二是可定位。** 每个会话的产物都聚在自己那个目录里，想让 AI 处理什么、想找它生成过的东西，来这里就行，不用在整块磁盘上翻。

::: tip 工作区内自动允许
工具权限里有个「工作区内自动允许」的选项。开启后，AI 在工作区里读写文件不再逐次弹确认卡片——因为它被限制在这个沙箱里，风险可控。

工作区之外的操作（比如访问别的路径）仍然会问。
:::

## 典型用法

**让它整理资料**：把几个文件导入工作区，然后说「把这三个表格合并成一个，输出到工作区」。它会用读文件工具读，用写文件工具写，你打开工作区就能看到结果。

**让它写代码**：工作区当项目目录用，让它创建、修改、运行。内置终端能看到它跑的每条命令和输出。

**临时存东西**：截图、复制的文本，扔进工作区当草稿区，聊完一起清。

## 注意事项

### 删会话不删工作区

删掉会话，对话记录没了，但工作区目录和里面的文件**仍然留在磁盘上**。

要真正删文件，得去左侧导航的「工作区」页，找到对应那条，点「删除这个会话工作区」。这一步不可恢复。

这个设计是有意的：误删会话不会连带丢文件。代价是清理得手动做，删得多了容易忘。

### 文件不会自动同步

工作区是本地目录，不走任何云端。换台机器就没了。

### 大文件别放进来

工作区会占用应用数据目录的空间，也会被计入「系统优化」页显示的占用统计。大文件建议放外面，需要时再导入。
