# AI 对话

DoroPet 的对话完全跑在你配置的模型服务上，应用本身不内置额度。

## 配置模型

在「设置 → 模型」里填写供应商、API Key 和模型名。支持自定义 Base URL，所以任何兼容 OpenAI 协议的端点都能接。

| 模型 | 决定回复质量与速度的主要因素 |

## 角色与人设

角色决定她怎么说话。内置角色可以直接用，也可以自己写提示词。

::: warning 提示词里的工具说明
不要在人设里手写工具说明。工具列表由程序按当轮实际可用的能力注入，写死在提示词里会导致她说自己有并不存在的功能。
:::

## 常见现象

**回复很慢** — 先看是不是模型本身慢，换个模型试；再看网络到供应商的连通性。

**答非所问、忘了前文** — 上下文长度被截断了。长会话建议主动开新对话。
