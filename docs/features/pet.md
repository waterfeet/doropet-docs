# 桌面宠物

Doro 是一个独立的透明窗口，浮在所有窗口之上（可通过设置调整层级）。

## 基本操作

### 拖动位置

按住左键拖动即可。松开后会记住位置，下次启动回到原处。

右键唤出功能轮盘，常用入口都收在这里。轮盘分两级，二级页会就地展开，不会跳走。

## 常驻与退出

关闭主窗口不会退出应用，Doro 会继续待在桌面上。彻底退出请走右键菜单里的「退出」，或托盘图标。
