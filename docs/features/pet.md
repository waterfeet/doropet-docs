# 桌面宠物

Doro 是一个独立的透明窗口，浮在桌面上。它有自己的形象、动画、台词，以及一整套围绕它的操作方式。

这篇把「怎么动她、怎么调她、怎么找到她」讲完。AI 对话、音乐、直播各有单独页面。

## 移动位置

**按住左键拖动**即可移动，松开后位置会被记住，下次启动回到原处。

多显示器或者分辨率变化后，Doro 可能跑到屏幕外。找回她的方式在菜单的「位置」里：

| 操作 | 效果 |
| --- | --- |
| 回到主窗口中心 | 把 Doro 移到主窗口附近 |
| 唤回屏幕中央 | 直接放到当前屏幕正中 |

## 调整大小

两种方式，效果一致：

- **鼠标滚轮**在 Doro 身上滚动
- 菜单里「缩放倍率」的 `-` / `重置` / `+` 按钮

缩放倍率的范围没有硬限制，但调到很小（比如 30%）时，右键菜单和轮盘会出现得比较局促，建议不要低于 50%。

## 右键菜单

右键 Doro 会唤出菜单。菜单分成两个部分：一个环形轮盘，一个设置面板。

### 轮盘

轮盘是一个环形的快捷入口，**点一下弹出，再点一下扇区确认**——不是「按住拖到扇区再松开」。

| 扇区 | 说明 |
| --- | --- |
| 主窗 | 显示或隐藏主窗口 |
| 隐藏 | 把 Doro 从桌面收起（不等于退出） |
| 溜达 | 让 Doro 自己在屏幕里走动，再点一次停止 |
| 跟随 | 让 Doro 追着鼠标跑，再点一次停止 |
| 吸附 | 靠近屏幕边缘时自动贴边 |
| 背包 | 展开背包二级页，可以直接选物品喂食 |
| 摸摸 | 摸一下 Doro，触发对应反应 |
| 退出 | 关闭 Doro 和主窗口，完全退出程序 |

轮盘的交互是**多页**的，不是所有操作都会立即关闭：

- 普通开关类操作，点了就执行并收起轮盘
- 「背包」这类会换页，**不收起**——你可以连着喂好几个物品，最外圈的状态环会同步变化，中央会闪一下「饱食 +25」这样的提示

::: tip 为什么背包要在轮盘里打开
主窗口的背包是个弹窗，弹窗会把宠物状态页挡住，你看不到喂食过程中数值怎么变。轮盘的背包二级页就解决了这个问题——状态环一直在最外圈，喂一个涨一截，看得很清楚。
:::

### 设置面板

设置面板是分卡片的，包含：

| 卡片 | 内容 |
| --- | --- |
| 表情 | 切换 Live2D 表情 |
| 动作 | 播放 Live2D 动作 |
| 行为 | 自由走动、追着鼠标跑、贴边停靠、镜像翻转 |
| 显示设置 | 缩放、透明度、鼠标穿透、直播可采集、刷新率 |
| Doro 说话 | 弹出频率、启动播报、聊天时显示、备忘录提醒 |
| 形象 | 切换 Live2D 模型 |

## 行为模式

三项互斥的自动运动，同一时刻只会开一个：

- **自由走动** —— 按自己的节奏在屏幕上踱步
- **追着鼠标跑** —— 鼠标移到哪，Doro 跟到哪
- **贴边停靠** —— 拖到屏幕边缘附近时自动吸附上去

三项都在菜单的「行为」里开关，开关状态即时生效，不需要重启。

## 显示设置

### 透明度

范围 20%–100%，拖动滑块实时生效。数值越低，Doro 越透。

### 鼠标穿透

开启后，鼠标点击会**穿过** Doro 落到下面的窗口上，等于把 Doro 变成纯装饰。

::: warning 开了穿透就点不到她了
鼠标穿透开启时，你无法通过鼠标操作 Doro——包括拖拽和右键。只能从主窗口或托盘菜单把它关掉。忘了这一点会以为 Doro「卡住了」。
:::

### 直播可采集

开启后，OBS 等采集软件才能在窗口列表里选到 Doro 的窗口。默认关闭，防止误采集。

### 刷新率

默认是「自动」，跟随显示器刷新率。笔记本为了省电，可以手动限制到 30 或 60 FPS。

## Doro 说话

控制她的主动发言行为：

| 选项 | 说明 |
| --- | --- |
| 允许弹出 | 总开关，关掉后她不会再主动说话 |
| 启动播报 | 启动时用语音播报一段简报 |
| 聊天时显示 | 对话内容是否在桌宠窗口上显示 |
| 备忘录定时提醒 | 到点的备忘录由 Doro 提醒你 |
| 频率 | 主动说话的密集程度 |

## 隐藏与找回

「隐藏」只是把窗口收起来，程序仍在运行。找回她的两种方式：

- **托盘图标**右键 → 显示桌宠 / 打开主窗口 / 退出
- 主窗口里切回桌宠页面

::: danger 隐藏和退出是两回事
点「隐藏」后程序还在后台跑，音乐和直播不受影响；点「退出」才会真正结束进程。如果你只是想把 Doro 收起来但保持功能运行，用「隐藏」。
:::

## 常见问题

### Doro 不见了

按顺序排查：托盘图标还在不在（在 → 被隐藏了）→ 菜单里点「唤回屏幕中央」（被拖到屏幕外了）→ 多显示器拔掉过的话，重新插上再唤回。

### 拖不动

鼠标穿透开着。去菜单或主窗口关掉。

### OBS 里选不到 Doro 窗口

「直播可采集」没开。

### 换显示器后位置错乱

不同显示器缩放比例不一样时会发生。用「唤回屏幕中央」重置即可。
