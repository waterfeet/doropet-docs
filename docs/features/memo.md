# 备忘与提醒

记一件事，到点让 Doro 提醒你。这是日常用得最多的小功能之一。

两种用法：让她帮你记，或者自己在备忘录页新建。

---

## 让 Doro 帮你记

不用打开备忘录页。她是你的专属小秘书，随时待命，说一句就行。

在对话里直接说：

> Doro，每天上午 11 点提醒我点午饭。

> Doro，等会下午三点十五提醒我开会。

她会做两件事：**先查当前时间**，再按你说的创建提醒。查时间是必须的——不然「下午三点十五」是哪天就说不清了。

### 她能听懂哪些说法

| 你说 | 她会建成 |
| --- | --- |
| 每天上午 11 点提醒我点午饭 | 周期提醒，每天 11:00 |
| 下午三点十五提醒我开会 | 一次性，今天 15:15 |
| 明天下午两点提醒我交作业 | 一次性，明天 14:00 |
| 每周一早上十点提醒我交小组作业 | 周期提醒，每周一 10:00 |
| 半小时后提醒我看锅 | 一次性，当前时间 +30 分钟 |

关键是**说清是「一次性」还是「每天/每周」**。只说「三点提醒我」她通常按一次性处理。

::: tip 前提是角色开了工具
这条路由的是 `create_reminder` 工具。如果角色没勾「启用工具调用」，她只会说「好的」，然后什么都没发生。
:::

### 她可能会反问

时间说模糊了（比如「晚点提醒我」），好的模型会追问具体时间，而不是自己猜一个。如果你发现她经常猜错，换个模型或者把时间说得更明确。

---

## 手动新建

侧栏的「备忘录」页，点 **「+ 新建备忘」**。

三个字段：

| 字段 | 说明 |
| --- | --- |
| **标题** | 提醒弹出时显示的主文案，简短些 |
| **内容** | 可选的补充说明 |
| **提醒设置** | 见下 |

### 提醒设置

| 类型 | 说明 |
| --- | --- |
| **一次性** | 指定某个具体时间，到点响一次 |
| **每天** | 每天同一时间 |
| **每周** | 每周同一天同一时间 |
| **自定义** | 自己写 cron 表达式，比如 `0 0 9 * * *` 表示每天 9 点 |

自定义那栏认的是 **cron**（秒 分 时 日 月 周），界面上有预设可选，也会把表达式翻译成人话给你确认。

不用提醒纯记事的话，把提醒关掉就行。

---

## 提醒响起时

由桌面上的 Doro 弹气泡告诉你。

::: warning 提醒不会出现在灵动岛
灵动岛只显示时间、音乐、占用这些常驻信息，**提醒不上岛**。这是有意的：避免同一条提醒在两处重复播报。

所以如果你的灵动岛是常开的，别指望在它上面看提醒——留意桌面上的 Doro。
:::

## 管理

列表里显示每条备忘的标题和内容摘要（前 80 字），顶部有搜索框。

可以：

- **搜索** —— 按关键词找，备忘多了很有用
- **启用 / 停用** —— 周期提醒可以临时关掉，不用删
- **删除** —— 会弹确认，「删除后不可恢复」

---

## 常见问题

### 到点没提醒

先确认应用还开着。提醒由应用进程调度，**退出应用之后就不会触发了**——它不像手机闹钟那样由系统托管。

### 她说创建了，但列表里没有

角色没开工具调用，或者这一轮工具被权限拦了。去备忘录页看一眼比信她的话可靠。

### 时间差了几分钟

她说「明天早上九点」时是按模型的理解算的。如果你的系统时间不准，结果就会偏。先对一下系统时钟。

### 周期提醒重复响

检查是不是建了两条——让她记一次、手动又加了一次，两条都会响。

### 提醒弹了但没声音

提醒是气泡 + 提示音。声音走的是应用内的提示音，检查系统音量以及应用是否被静音。
