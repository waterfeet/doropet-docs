# 音乐与歌词

DoroPet 内置了完整的播放器：搜索、播放、歌词、桌面歌词、全屏可视化。

## 搜索与播放

在音乐页搜歌名、歌手或歌单，点一下就播。

音源有两个：**网易云** 和 **酷我**。搜索时可以切换来源——某首歌在一个源搜不到，换另一个试试，这是实际使用里最常做的事。酷我的歌带来源角标，能播、也有歌词。

## 播放控制

两处都能控：

- **音乐页**：完整功能，播放列表、歌单管理都在这里
- **灵动岛**：收起状态下就能暂停、切歌、拖进度，不用切回主窗口

两边操作是同步的，在哪边点都一样。详见 [灵动岛](/features/island)。

## 歌词

两种形态。

### 桌面歌词

浮在桌面上的歌词条，底色、字号、字色都能自定义，支持完全透明背景。

支持卡拉 OK 式逐字扫过，长句折成两行，底部带进度条。

**锁定**之后不再挡鼠标——你可以正常点桌面上的东西，要解锁点一下卡片上的按钮。位置会被记住。

### 全屏可视化

播放时可以把歌词做成铺满全屏的视觉，按整首歌的节奏编排光位和线稿。

::: tip 性能
可视化对显卡有要求。最大化后明显掉帧的话，调低画质或换简洁样式。切到别的页面时它会暂停渲染，回来接着播，进度不重置。
:::

## 常见现象

**放了没声音** — 先看系统输出设备有没有被别的应用独占，再看应用内音量。

**歌词对不上** — 部分歌曲没有时间轴歌词，只能滚动显示全文，这是音源本身的限制。

**搜不到某首歌** — 换音源。

**桌面歌词挡住操作** — 开锁定，锁定状态不接收鼠标。
