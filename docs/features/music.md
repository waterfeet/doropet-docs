## 歌词可视化

播放时可以把歌词以可视化形式铺满屏幕。切换到其他页面时，可视化会暂停渲染，回来接着播，不会重置进度。

::: tip 性能
可视化对显卡有一定要求。如果窗口最大化后明显掉帧，可以调低画质或改用简洁样式。
:::

## 常见现象

**放了没声音** — 检查系统输出设备是否被其他应用独占，以及应用内的音量是否被拉到 0。

**歌词对不上** — 部分歌曲没有时间轴歌词，只能滚动显示全文，这是音源本身的限制。
