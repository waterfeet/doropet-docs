# 灵动岛

屏幕顶部居中浮着的那条细长信息条。平时收成一条胶囊，鼠标移上去展开成一块面板。

它是个独立窗口，浮在所有窗口之上——不占主窗口，也不挡桌面上的 Doro。

## 它显示什么

收起态可以自定义显示内容，可选项包括：

| 内容 | 说明 |
| --- | --- |
| 时间 | 时钟 |
| 当前播放 | 歌名、歌手 |
| 歌词 | 当前这一句 |
| CPU / 内存占用 | 系统资源 |
| 律动频谱 | 随音乐跳动的小频谱 |

宽度会按实际文字长度自适应——歌词换行不会让窗口反复伸缩。

## 能操作音乐

不用切回主窗口：

- 胶囊上有播放控制，可以直接暂停、切歌、调进度
- 点歌名能直接打开音乐页
- 进度条、播放键、当前歌词的逐字高亮，颜色都跟着主题色走

## 打开与关闭

设置 → **「灵动岛」**，第一项就是总开关 **「屏幕顶部信息条」**。

打开即随应用启动出现，不需要额外配置。

::: tip 它和桌宠是两个东西
灵动岛是屏幕顶部那条信息条；桌宠是桌面上那个会动的 Doro。两者独立开关，互不影响。
:::

## 配置项

### 主题色

六个预设：**桃粉、薰衣草、晴蓝、薄荷、蜜橙、石墨**，外加一个「自定义」可以自己调色。

色值作用于进度条、播放键、逐字歌词高亮、胶囊上的小频谱——不是整条背景都染色，所以不需要担心太花。

### 明暗

| 选项 | 行为 |
| --- | --- |
| **跟随应用** | 主界面切深色时它也跟着变 |
| **深色** | 固定深色玻璃底 |
| **浅色** | 固定浅色玻璃底 |

桌面是深色壁纸就用深色，反之亦然。跟随应用最省心。

### 位置

有个「距屏幕上沿」的滑块，可以把它往下挪一点（0–60 像素区间），避免和自己的任务栏或者某些应用的顶栏打架。

## 提醒不上岛

这点容易误会：**短信、备忘提醒不会出现在灵动岛上**。

提醒走的是桌宠气泡和备忘页——避免同一个提醒在两处重复播报。

## 常见问题

### 被别的窗口盖住了

正常情况下它会自己保持置顶，切换虚拟桌面、进出全屏、锁屏解锁之后都还在最上层。如果确实被盖住了，把总开关关掉再打开一次。

### 挡到东西了

往下挪位置，或者直接关掉——它只是信息展示，关了不影响任何功能。

### 歌词不显示

歌词来源是音乐模块，没在播放就没有歌词可显示。
