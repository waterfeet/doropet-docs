## 技能 & 工具

侧栏的「技能 & 工具」页，分三块：

| 分栏 | 内容 |
| --- | --- |
| **内置工具** | 系统提供的可执行工具，由模型自行调用。和 [工具调用](/features/chat/tools) 里那份清单是同一套 |
| **自定义技能** | 提示词型技能：写下描述，模型读到之后会用现有工具去完成这个目标 |
| **技能市场** | 浏览并安装别人做的技能 |

右上角有 **「+ 安装技能」**。没装过时显示「暂无自定义技能，点击右上角按钮安装」。

::: warning 技能市场依赖外部服务
它不是本地功能，需要联网访问第三方技能库。网络不通、或者那个服务本身不可用时，这一栏会是空的或者加载失败——这不影响内置工具和已安装的自定义技能。
:::

## 内置终端

一个独立窗口，用来**看她到底在跑什么命令**。

AI 调用 `run_command` 执行命令时，这里会实时打出完整命令、输出和退出码。你觉得不对劲，可以在这里直接看到，而不是只信她的转述。

### 自己敲

也可以当普通终端用。有些操作自己敲两下比让她做更快。

- 命令跑太久，`Ctrl + C` 取消
- 输入暂停时会显示提示（「输入已暂停 · Ctrl+C 可取消」）
- 终端配色有多套可选

## 系统优化

侧栏的「系统优化」页，三块信息：

### 内存

显示总内存、已使用、占用百分比，以及可释放的量。

点释放后只**修剪进程的工作集**——不会删除任何文件，也不会关掉任何程序。效果是让 Windows 把闲置的内存页换出去，属于「清一下缓存」，不是「杀进程」。

### 磁盘空间

列出各个盘符的使用率，一眼看出哪个盘要满了。

### 系统信息

处理器型号、逻辑核心数、物理内存、操作系统版本。

## 日志

运行日志页，记录了程序的各类事件。

**排查问题的第一现场**。应用崩溃、功能报错、更新失败时，先来这里看最后几条——比猜测快得多。

## 友情链接

「资源收藏墙」，收藏一些 UP 主和资源。

其中有个 **「翻牌子 · 随机认识一位 UP 主」**：随机抽一个出来，显示他的资料、粉丝数、关注数和简介。不满意可以「洗牌再来一轮」。

纯娱乐性质，和工作流那些没关系。
