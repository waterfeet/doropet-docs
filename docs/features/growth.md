# 养成与 Doro 币

桌面上的 Doro 不只是个会动的模型——她有状态、会饿、会脏、会闹脾气，也有自己的钱包。

这套东西集中在**主页**：钱包、三条属性、四个快捷入口都在一屏里。

## 三条属性

| 属性 | 低于 30% | 低于 60% | 正常 |
| --- | --- | --- | --- |
| **饱食度** | 「Doro 饿了，喂点东西吧」 | 「还能撑一会儿」 | 「肚子饱饱的」 |
| **清洁度** | 「该洗个澡了」 | 「有点灰扑扑」 | 「干干净净」 |
| **心情** | 「想多陪陪你」 | 「还算平静」 | 「心情很好」 |

三样都会**随时间自然衰减**——不是不玩就没事，是放着不管会越来越差。

所以这个功能的核心其实是一句话：**常回来看看她**。

颜色也跟着变：60% 以上是绿的，30–60% 是常规色，低于 30% 变红。

### 怎么补

| 属性 | 补充方式 |
| --- | --- |
| 饱食度 | 喂东西。食物从商店买，在背包里 |
| 清洁度 | 清洁 |
| 心情 | 摸摸她、互动、玩具，以及五子棋（输了也加心情） |

投喂和清洁在桌宠右键轮盘里也能直接做，不用每次都打开主页。

## Doro 币

主页面右上角显示当前余额，**点一下会弹出获取方式**。完整清单：

| 方式 | 收益 | 限制 |
| --- | --- | --- |
| 每日登录 | +20 | 每天一次 |
| 在线每小时 | +5 | 挂着就行 |
| 每次 AI 对话 | +3 | 每天前 30 轮 |
| 摸摸 Doro | +1 | 每天前 5 次 |
| 外出打工 | +12 ~ 40 | 看目的地 |
| **五子棋获胜** | **+100** | 每天前 5 局结算 |
| 解锁成就 | +10 ~ 1000 | 一次性的 |

::: tip 币其实不难攒
日常聊天、摸两下、每天开一次，一个月下来几千币很轻松。**五子棋是单次收益最高的一项**——赢一局 100 币，抵得上三十多轮对话。

输一局也不亏：+10 币 +50 心情。所以哪怕下不过，前 5 局也值得下完。
:::

## 四个入口

主页那排快捷按钮：

| 入口 | 作用 |
| --- | --- |
| **商店** | 用 Doro 币换食物和玩具 |
| **背包** | 看囤了什么，从这里喂食、使用玩具 |
| **外出** | 带她出去走走 |
| **成就** | 显示已解锁数量，解锁有币拿 |

## 外出

点「外出」选一个目的地，她会离开一会儿——页面上有倒计时（「Doro 外出中…… N 秒后回来」）。

回来时给个结果，可能带回币，也可能花掉币，取决于去的什么地方：

- **打工**类目的地 → 赚 12~40 币
- 其他目的地 → 通常是花钱换心情或带回小玩意

外出期间不能重复点，得等她回来。

## 五子棋

侧栏有独立的 [五子棋](/features/gomoku) 页，和 Doro 下一盘。

结算规则：

- **赢** → +100 Doro 币
- **输** → +10 币、+50 心情
- 每天**前 5 局**才结算，之后不再给奖励
- **悔棋的局不计奖励**

所以这是个稳定的币来源，也顺便涨心情。

## 陪伴天数

主页显示「陪伴 N 天」，从第一次使用算起。旁边还有当前心情标签和已装备的称号。

称号和成就挂钩，解锁之后可以在成就页装备。

## 一点说明

这些数值是**跟着本地数据走的**，不联网校验。想改当然改得了，但那等于把养成玩成签到——没什么意思，也没必要。
