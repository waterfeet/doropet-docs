# 第一次启动

装好之后第一次打开，会经历几个步骤。按顺序走完，Doro 就能上桌了。

## 1. 配置对话模型

DoroPet 本身不带模型额度，需要接一个你自己的模型服务。

到左侧导航的 **「模型配置」** 页，点 **「+ 新建模型」**，填名称、供应商、API Key、模型，保存时把「设为默认」勾上。

不知道选哪家、Key 去哪里拿、各种报错什么意思，都写在 [配置对话模型](/guide/model-setup) 里，那是这一节的详细版。

配好后回对话页发一句「你好」，能回复就说明通了。

## 2. 设定角色

默认内置了几个角色，也可以自己写。角色的提示词决定了她说话的语气、边界和习惯。

::: tip 建议
先别急着改提示词。用默认角色跑几天，等你能说出「她哪里不对劲」，再动笔改会更准。
:::

## 3. 桌面出现

配置完成后，Doro 会出现在桌面右下角。此时你可以：

- **拖拽** 移动到任意位置，位置会被记住
- **右键** 唤出功能轮盘
- **滚轮 / 拖拽边角** 调整大小

## 4. 接下来做什么

- 想让她记住事情 → 看看对话里的记忆功能
- 想听歌 → [音乐与歌词](/features/music)
