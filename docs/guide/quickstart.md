# 第一次启动

装好之后第一次打开，会经历几个步骤。按顺序走完，Doro 就能上桌了。

## 1. 选择模型

DoroPet 的对话能力来自你自己接入的模型服务，应用本身不代管密钥。

填入 API Key 后点「测试连接」，成功即表示配置可用。

## 2. 设定角色

默认内置了几个角色，也可以自己写。角色的提示词决定了她说话的语气、边界和习惯。

::: tip 建议
先别急着改提示词。用默认角色跑几天，等你能说出「她哪里不对劲」，再动笔改会更准。
:::

## 3. 桌面出现

配置完成后，Doro 会出现在桌面右下角。此时你可以：

- **拖拽** 移动到任意位置，位置会被记住
- **右键** 唤出功能轮盘
- **滚轮 / 拖拽边角** 调整大小

## 4. 接下来做什么

- 想让她记住事情 → 看看对话里的记忆功能
- 想听歌 → [音乐与歌词](/features/music)
