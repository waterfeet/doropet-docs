# 安装 DoroPet

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上，或 Windows 11 |
| 运行环境 | WebView2 Runtime（Win11 自带；Win10 多数已预装，缺失时安装器会处理） |
| 磁盘空间 | 建议预留 500 MB 以上 |
| 内存 | 建议 4 GB 以上 |
| 网络 | 首次启动需要联网 |

目前发布的是 **Windows x64** 版本，其他平台暂未提供安装包。

:::

## 安装

1. **双击安装包**。首先会让你选择安装界面的语言（简体中文 / English），选哪个都不影响程序本身的语言。
2. **跟着向导走完**。安装到当前用户目录，**不需要管理员权限**，不会弹 UAC 提权窗口，也不会装到 `Program Files`。
3. **等待解包完成**。安装程序会一并解出主程序、内置的音源服务和默认 Live2D 模型。

::: warning 杀毒软件可能拦截
DoroPet 没有购买代码签名证书。部分安全软件（尤其对「未知发行者」策略较严的）会拦截运行，甚至直接把安装包当威胁删掉。

遇到拦截时：先把安装包加入信任列表，再重新运行。如果安装包已经被删除，需要重新下载一次——被删掉的那份通常已经损坏，原地重试往往还是失败。
:::

## 首次启动

第一次打开会经历这几件事：

1. **防火墙提示**（如果出现）—— 允许即可，本地功能需要回环通信。
2. **初始配置** —— 填写模型服务的 API Key 等信息，详见 [配置对话模型](/guide/model-setup)。
3. **Doro 出现在桌面右下角** —— 位置和大小都会被记住，下次启动回到原处。

如果窗口一片空白，或者桌面上什么都没出现，先看 [常见问题](/faq)。

## 更新

应用内「检查更新」拉取最新版本。更新源在国内，下载通常不慢。

更新方式是**后台下载 + 被动安装**：不会弹全屏安装向导打断你手上的事，装完自动重启。

::: tip 更新不碰你的数据
升级只替换程序文件。对话记录、记忆、模型配置、自定义 Live2D 模型都在用户数据目录里，不会被覆盖。

反过来说，想彻底重置也得手动去清那个目录——卸载程序不负责这件事。
:::

## 卸载

在 Windows「设置 → 应用 → 已安装的应用」里找到 DoroPet 卸载即可。

卸载会移除程序和安装目录，但**不会删除用户数据**。你的对话记录、记忆、歌单、工作区文件和 QQ 接入配置都还在，重装后能直接接着用。

想彻底清理，手动删掉这个目录：

```
%APPDATA%\com.waterfeet.doropet
```

里面主要是这些：

| 内容 | 说明 |
| --- | --- |
| `doropet.db` | SQLite 数据库，对话、记忆、设置都在里面 |
| `logs\` | 运行日志，排查问题时会用到 |
| `playlists\` | 你保存的歌单 |
| `workspaces\` | 工作区文件 |
| `napcat_agent.json` / `qqbot_official.json` | QQ 接入配置 |

::: tip 改过数据目录的话
如果你在设置里换过数据存放位置，真实路径记在同目录的 `.data_dir.json` 里，按它指的位置去找。
:::
