# 安装 DoroPet

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11 |
| 运行库 | WebView2 Runtime（Win11 自带，Win10 通常已预装） |
| 磁盘空间 | 约 300 MB，含默认模型 |
| 网络 | 首次启动需要联网下载模型与依赖 |

## 下载

到 [官网](https://www.doropet.com) 的下载页获取最新安装包。建议始终使用官网版本，第三方渠道的包可能被改动过。

## 安装步骤

1. 双击安装包，按向导完成安装。
2. 首次启动时 Windows 可能弹出防火墙提示，允许即可（用于本地功能通信）。
3. 安装完成后自动进入初始配置。

::: warning 关于杀毒软件
DoroPet 是未签名的个人项目，部分杀毒软件可能误报。如果安装包被拦截，请手动添加信任后重试。

## 升级

应用内「检查更新」会拉取最新版本并自动重启完成升级。升级不会清空你的配置、对话记录和模型文件。
